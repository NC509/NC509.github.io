# ReadMe

## Purpose of Repository
This repository pertains to the creation of my github.io portfolio page. The page produced from this repository will showcase my projects that I have been working on! The link to view my project portfolio is provided below. 

Project Portfolio: https://nc509.github.io/ 

## Tutorial
I have included a step by step tutorial on how to make a GitHub.io e-portfolio similar to mine. In these steps I explain how to make a GitHub repository, use the **"minimal"** template, and how to customize this template to make a simple e-portfolio that can host a user's projects. 

To see this tutorial please visit this page: ["Noah's e-portfolio tutorial"](https://nc509.github.io/E-Portfolio%20Tutorial/)

## Resources used
The portfolio template that I used to make this portfolio was extracted from a simple theme called "minimal". 

The link for this template used is the following: https://github.com/pages-themes/minimal
