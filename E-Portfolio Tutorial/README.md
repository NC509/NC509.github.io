# Readme

This folder pertains to a page that is a step by step guide on how to make a GitHub.io e-portfolio similar to mine. In these steps I explain how to make a GitHub repository, use the ["minimal"](https://github.com/pages-themes/minimal) template, and how to customize this template to make a simple e-portfolio that can host a user's projects. 

To see this tutorial please visit this page: ["Noah's e-portfolio tutorial"](https://nc509.github.io/E-Portfolio%20Tutorial/)
